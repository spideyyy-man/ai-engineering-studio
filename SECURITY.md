# Security

AI Engineering Studio is a **local, single-user tool with no login**. Run it on your own machine and don't expose it to a network. The README's "Security notes" section lists the safeguards that are in place (upload limits, restricted file and URL loading, localhost-only Docker ports).

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Instead, contact the maintainer privately on GitHub (@spideyyy-man) with:

- what the problem is and which part of the app it affects,
- steps to reproduce,
- the impact you think it has.

You'll get a reply as soon as possible, and credit in the fix if you'd like it.

## Supported versions

Only the latest code on `main` gets security fixes.
